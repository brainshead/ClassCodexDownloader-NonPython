# ClassCodex Downloader — Non-Python Edition

An independent, non-Python adaptation of WoWClassCodexDownloader, for users who prefer Windows PowerShell or macOS shell scripts.

This is not the official downloader and is not intended to replace or impersonate the original project.

## v1.16.6

- Fixes over-escaped PowerShell regular expressions that crashed the detailed update summary.
- Corrects Icy Veins export and label matching plus UGG item popularity matching.
- Normalizes Windows snapshot data paths.
- Retains the Windows updater, detailed diff utility, macOS scripts, configurable AddOns path, incremental updates, manifest/SHA-256 verification, and snapshot history.

See CHANGELOG-v1.16.6.txt for repair notes.
