# ClassCodex Downloader — Non-Python Edition

An independent, non-Python adaptation of WoWClassCodexDownloader, for users who prefer Windows PowerShell or macOS shell scripts.

This is not the official downloader and is not intended to replace or impersonate the original project.

## v1.16.5

- Windows updater and detailed diff utility
- BAT launcher handles the downloaded-file mark for the diff script without changing system-wide execution policy
- Automatic WoW install discovery skips inaccessible network-path candidates
- macOS updater and diff utility (Bash)
- Configurable AddOns target path, incremental updates, manifest and SHA-256 verification
- Independent snapshots for history/rollback
- Icy Veins export diff with class/spec/hero-tree/profile detection
- UGG item popularity diff

See CHANGELOG-v1.16.5.txt for repair notes.

Version: 1.16.5. Test against a separate AddOns folder before using on a live installation.
